# JotCue user promo

This folder contains a 36.5-second, vertical (1080 x 1920) user promo for JotCue.

## Story

1. Meet JotCue: notes that know what comes next.
2. Tap `+` and write naturally.
3. Start a line with `- ` or accept a plan-to-tasks suggestion.
4. Write a natural reminder phrase, review the cue, and tap **Add**.
5. Pin, search, filter, and keep working offline.

## Voiceover

> Busy thoughts deserve better than sticky notes and forgotten alarms. Meet JotCue. Tap plus and write naturally. Start a line with a dash to make it a task. Add a few plan steps, and JotCue can turn them into a checklist. Write “Remind me Monday at six,” review the suggested cue, and tap Add. Pin favorites, filter by category, or search in seconds. Your notes stay available offline and sync when you're back. Jot it down. We’ll cue the rest.

## Deliverables

- `jotcue-user-promo.mp4`: ready-to-share H.264/AAC promo with narration and a subtle original music bed.
- `jotcue-user-promo-cover.png`: cover image for sharing or uploading.
- `scenes/`: the six vertical storyboard plates used in the final cut.

## Re-render

1. Run `build-scene-plates.py` to recreate the visual plates.
2. Run `build-music-bed.py` to recreate the original music bed.
3. Run `render-promo.ps1` from Windows PowerShell to produce the MP4.
